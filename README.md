# hamsterprojekt.github.io

The website of [HamsterProjekt](https://github.com/HamsterProjekt), served by
GitHub Pages at <https://hamsterprojekt.github.io/>.

It is plain HTML and CSS, no build step. Open `index.html` in a browser, or:

```bash
python3 -m http.server 8000
```

`assets/hamsterprojekt.css` and the icons are copies from
[HamsterProjekt/.github](https://github.com/HamsterProjekt/.github) (see its
`STYLE.md`); change them there first, then copy them here. Page layout lives
in `assets/site.css`.
