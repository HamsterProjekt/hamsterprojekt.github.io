Track your time from the Plasma panel. Keep it in plain text.

HamsterProjekt keeps the Hamster time tracker alive and brings it to KDE Plasma 6, with a backend that stores every activity in Markdown files you can read, edit and sync yourself.

What it adds

A Plasma 6 panel widget

Shows the current activity and its time in the panel. Start, stop and continue activities from the popup, with autocompletion and the day's totals.

Markdown storage

Facts, activities, categories and tags in plain Markdown files instead of SQLite. Edit them by hand, keep them in git, sync them with Syncthing or Nextcloud.

Kirigami windows

The overview, edit and settings windows rewritten with Qt Quick and Kirigami, so they follow your Plasma theme. A service that runs without GTK sits underneath.

Nothing taken away

SQLite stays the default, the GTK windows are untouched, and Hamster's data model, D-Bus methods and activity@category, description, #tag entry are unchanged.

Easy to install

A Flatpak with the widget next to it, or two git checkouts and one script. Everything goes under your home directory.

Side by side with upstream

Its own io.github.HamsterProjekt.* names, so upstream Hamster can stay installed next to it.

Your time, in files you own

With HAMSTER_STORAGE=markdown the Hamster service writes one file per month, and one for your categories, activities and tags:

~/.local/share/hamster/markdown/2026-11.md
~/.local/share/hamster/markdown/activities.md

Each day is a heading, each activity a list item, written the way you would type it into Hamster. Change a line in your editor and the widget picks it up.

Install

For KDE Plasma 6; the guide has the packages for Kubuntu, KDE neon and Debian. Pick one way:

Flatpak · quickest

The windows and the Markdown backend in a sandbox, plus the panel widget. Download the latest release:

for f in hamster-kde.flatpak hamster-kde.plasmoid install-flatpak-widget.sh; do
  wget -N "https://github.com/HamsterProjekt/hamster-kde/releases/latest/download/$f"
done
flatpak install --user hamster-kde.flatpak
sh install-flatpak-widget.sh

Then add “Hamster Time Tracker” to a panel. The Flatpak keeps its files under ~/.var/app/.

From source · recommended

Widget, windows and backend, running from two git checkouts and updated with git pull:

git clone https://github.com/HamsterProjekt/hamster.git ~/projects/hamster
git clone https://github.com/HamsterProjekt/hamster-kde.git ~/projects/hamster-kde
cd ~/projects/hamster-kde && ./install.sh

Needs a few packages first (PyQt6, Kirigami, PyGObject); the guide lists them per distribution.

Relationship to Project Hamster

Hamster is a good tool, but upstream development has slowed: the last release, 3.0.3, is from November 2023. HamsterProjekt is an independent fork that aims to keep it alive. It is not affiliated with or endorsed by the upstream maintainers.

We would rather see upstream thrive than fork forever. Changes that make sense for everyone are kept small so they can be offered upstream, and if upstream becomes active again we are happy to converge.

Hamster was written mainly by Toms Bauģis and Patryk Zawadzki, with contributions from many others, and later maintained by Eric Goller and the Project Hamster community. All credit for Hamster itself goes to them.

Bug reports, patches and “this works on my distro” messages are all welcome: see CONTRIBUTING.md.
